# BKAV Home Uninstaller Support Tool

A Windows Forms utility to detect and uninstall **BKAV Home** antivirus software.

## Features

- Detects if BKAV Home is installed on the system
- Displays current Windows OS information
- Launches the BKAV Home uninstaller
- Auto-exits after 5 seconds if BKAV Home is not installed
- Displays real-time system clock in the title bar

## Requirements

- Windows OS (x64/x86)
- .NET Framework 4.6 or higher

## Build

Open `frmbkavhome.slnx` in Visual Studio and build the solution.

## Usage

1. Run **BKAV Home Uninstaller.exe**
2. If BKAV Home is installed → Click **Remove** to uninstall
3. If BKAV Home is not installed → App will auto-exit in 5 seconds
