# Release v1.0.0 - BKAV Home Uninstaller Support Tool

## Overview
BKAV Home Uninstaller Support Tool is a lightweight Windows desktop utility designed to safely detect and uninstall BKAV Home antivirus software from your system.

## ✨ Features

- **BKAV Home Detection**: Automatically detects if BKAV Home is installed on your system
- **Safe Uninstallation**: Provides a guided uninstallation process using the official uninstaller
- **System Information Display**: Shows your operating system version and architecture
- **Auto-exit Functionality**: Automatically closes the application after 5 seconds if BKAV Home is not detected
- **Real-time Clock**: Displays current system date and time in the window title
- **User-friendly Interface**: Simple and intuitive Windows Forms UI

## 📋 System Requirements

- **Operating System**: Windows XP or later
- **.NET Framework**: 4.6 or higher
- **Permissions**: Administrator rights may be required for uninstallation
- **Architecture**: 32-bit or 64-bit compatible

## 🚀 Installation & Usage

1. Download the latest release
2. Extract the files to your desired location
3. Run `frmbkavhome.exe`
4. The tool will automatically detect BKAV Home installation status
5. Click **Remove** to uninstall BKAV Home if detected
6. Follow the uninstaller prompts to complete the removal process
7. Click **Delete Leftover** to remove any remaining files after uninstallation

## 🔍 Supported Operating Systems

- Windows XP (NT 5.1.2600)
- Windows Server 2003 (NT 5.2.3790)
- Windows Vista and later
- Both 32-bit and 64-bit architectures
